# Original EGA sprite drawing

The EGA sprite comparison now extends through the original drawing routines
and their masked video-memory writes. The existing native conversion/pixel
check remains the source-data prerequisite.

`oracles/ega_sprite_blits.py` verifies the original main/EGA executable hashes,
applies MZ relocations, runs the main packed-sprite converter at 1239:0ccd,
and installs its actual output into the EGA driver. It then executes drawing
entry 1000:2104 with source crop metadata, clipping, reflection and copy mode.
The driver selects its own native drawing loops. None is intercepted.

The destination model handles the write mode used by these sprite paths:
mode 2, all four planes enabled, replacement logic, and a programmable bit
mask. A CPU color byte expands to four plane bits under that mask. Every
partial write must have a fresh read of the same destination byte; unsupported
write modes, plane masks, raster operations, output ports, byte sizes and
out-of-screen accesses assert rather than silently approximate. Read-mode
color comparison/plane reads are computed from the destination pixels.
This is a bounded model for the observed sprite path, not a complete EGA
hardware emulator or physical-display test.

Calibration uses a known two-row image crossing a destination byte boundary,
including transparency and all palette indices, in all four reflections.
It exposed an initialization requirement: reflected draws use the bit-reversal
table generated by native routine 1000:33b2. The oracle runs that initializer
and verifies all 256 entries before calibration. The initial missing-table
failure belonged to the test setup; no game repair was justified.

The corpus matrix contains all 722 sprites from the 12 intact PZ4 scenes,
each in all four orientations. Cases cover an ordinary draw, left clipping,
bottom/right clipping and top clipping, alternating full-screen and original
scene clip rectangles. The first sprite of each puzzle also covers opaque
copy and color-7 silhouette in all four orientations. These 2,984 complete
320x200 framebuffer hashes include 423,000 native masked byte writes.

Rust independently loads the source assets and draws into the same initialized
indexed destination. Every framebuffer hash matches. No production behavior
changed in this increment. The shared VGA/EGA fixture checker also retains
the 3,684 VGA cases and checks both fixture counts exactly.

The rebuilt game also completed all 30 original preset-piece selections in
real Xvfb windows: 386 mouse placements, no auto-solve, with debugger-confirmed
completion and return to the browser. The EGA P11 tray-toggle check preserved
board pixels and found visible pickup-caption glyphs. See
`ega-sprite-blits-window-preset.log` and `window-preset-debug.log`.

```
python3 validation/oracles/ega_sprite_blits.py /tmp/mickey-original-unpacked/final/output.000.exe /tmp/mickey-ega-unpacked/output.000.exe /tmp/preset-native-corpus validation/ega-sprite-blits.tsv
cargo test ega_sprite_blits_match_original_driver
```

Malformed P06 PZ4 and absent P07/P10 PZ4 remain documented VGA fallbacks.
This matrix does not cover every possible clip/flag/register state or every
recursively rendered scene frame. Physical EGA page switching, timing, other
write modes and analog display behavior are outside the model.
