# Porting Gaps & Feature Completeness Matrix (PR #12)

This document compares the original **Mickey's Jigsaw Puzzles (1991 DOS)** executable (`MICKEY.EXE`, unpacked SHA-256 `565a5c5601ede858cfdc289e6dd1f3bbde7c2ec2399e52dad2dce3d1b165d465`, analyzed via Ghidra 12.2 / REA) and original game assets against the current Rust port (`mickeys-jigsaw-rs` at `origin/main` commit `48a7464`).

## Classification Legend

- **complete**: Behavior matches the original game (or provides a full modern desktop equivalent with no user-visible loss).
- **partial**: Core feature exists, but significant original interactions, feedback, or edge cases are missing.
- **missing**: Confirmed in `MICKEY.EXE` / assets with no equivalent in the Rust port.
- **intentionally unsupported**: Obsolete 1991 DOS hardware interfaces (parallel port printers, CGA/Hercules/Tandy video, DOS joystick port, Sound Blaster/LPT Sound Source I/O ports) that do not apply to modern desktops.
- **unverified**: Observed in `MICKEY.EXE` but exact runtime semantics require further dynamic verification.
